# Carbon Tourism Research Website

A responsive, static website that can be published for free with **GitHub Pages**.

## Included
- `index.html` — page content and sections
- `style.css` — responsive styling and brand colours
- `script.js` — mobile navigation, expandable knowledge cards, illustrative carbon calculator, and demo survey preview

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public repository** (for example, `carbon-tourism-research`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the **root** of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will appear in the Pages section and usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Replace `your.email@example.com` in `index.html` with the project's actual contact email.
- Verify all study figures and research descriptions against the final article.
- The calculator uses simplified demonstration emission factors, not verified factors. Do not use it for formal carbon accounting without replacing them with documented, suitable factors and explaining the methodology.
- The survey form is **not connected** to a database or survey service. It only shows a preview and does not send/store answers. Connect it to an approved service (such as Qualtrics or Google Forms) before collecting real responses.
- Google Fonts are loaded from the internet; the page uses fallback fonts if unavailable.

## Local preview
Open `index.html` in a browser. For a local server, use VS Code's Live Server extension.
